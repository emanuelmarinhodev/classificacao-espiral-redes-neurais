# Classificação do Problema das Duas Espirais com Redes Neurais 🧠

Este projeto implementa Redes Neurais Artificiais (RNAs) **do zero**, utilizando apenas operações algébricas com `numpy`, para resolver o clássico problema de classificação não-linear das Duas Espirais.

## 🚀 Tecnologias Utilizadas
* Python
* NumPy (Cálculo de gradientes, backpropagation e álgebra linear)
* Pandas & Seaborn (Manipulação e visualização de dados)

## 📊 Modelos Implementados
1. **Perceptron Simples** e **ADALINE:** Demonstração da limitação de modelos lineares.
2. **Multilayer Perceptron (MLP):** Implementação completa do algoritmo de Backpropagation.
3. **Rede de Função de Base Radial (RBF):** Utilização de K-centers e cálculo da Pseudo-Inversa, alcançando >99% de acurácia.

## 📈 Resultados
O projeto inclui simulações de Monte Carlo (500 rodadas) para extração de métricas estatísticas (Acurácia, Sensibilidade, Especificidade, F1-Score) e análise detalhada de **Underfitting e Overfitting** através de matrizes de confusão e curvas de aprendizado.
